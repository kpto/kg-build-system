| File | What it shows |

| `03-detail-node.png` | **Open Detail** explicitly creates the `target` document and changes the angle. |
| `04-topology-property.png` | `target.approvedSymbol` inspected after clicking a property row. The tab strip still has only **Graph**; the Inspect header, property row and meaning change in place. |
| `05-detail-property.png` | **Open Detail** explicitly creates the property document and switches the angle. |
| `06-detail-graph.png` | The pinned **Graph** document viewed in Detail: graph meaning in the editor and counts in the Graph bottom tab. |

A tab is an explicitly opened document. Single-click inspection — a node or a property — never opens one.
