# kg-build-system

Declarative, typed, reproducible knowledge-graph builds.

The authoring guide in `docs/` is the review surface for framework changes.
Start at `docs/index.md`; `STYLE.md` is the writing brief.

```console
uv run mkdocs serve
uv run mkdocs build --strict
```

The framework is experimental; the guide describes the current model, not a
compatibility promise.
